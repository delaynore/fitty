Согласованная сборка #114

  • Шапка тренировки: убран счётчик Упр. X/N — остались ←, лампа + название недели и кнопка Облегчить (больше воздуха на 360 dp).
  • Нижняя панель: ← · ≡ План · → (на обычных) или чистая 🏁 Завершить (на последнем, без постоянной подписи «удерживайте»).
  • Удержание 1,2 с: плавная линейная заливка ярким лаймом слева направо с инверсией цвета текста/иконки; на короткий тап при ≥ 1 подходе — лёгкое встряхивание и морфинг текста прямо в кнопке на Удерживайте 1,2 с (~2 с); при 0 подходах — приглушённая, но нажимаемая без удержания.
  • Шторка «Все упражнения»: сегментная полоса прогресса + закреплённый баннер активной планки + вертикальный таймлайн с узлами и счётчиками 3/3 + компактный однострочный низ (Отменить | 🏁 Завершить).
  • Карточка техники (C): полное название без обрезки, одна строка метаданных (мышцы, оборудование, сложность), карточка техники и кнопка-карточка «Заменить упражнение · Только на сегодняшнюю тренировку».
  • Защитные шторки (C): для 0 подходов — инфо-карточка + «Вернуться» / «Отменить»; для планки и/или черновика — двухчастная карточка «Сохранится в историю / Не сохранится при завершении».
