Контекст:
Чип «Прошлый раз» (подход 1):
Состояние:

Итоговая комбинация (пунктир + тональная → лаймовая ✓)

1. До ввода — пунктир, серый placeholder, тональная ✓
2. Ввёл «7» — вес пунктиром, повт. белым с лайм-рамкой, яркая ✓
3. После нажатия ✓ — зелёная строка, спокойная ✓

Правила поведения

  • Незатронутое поле показывает подсказку Fitty как серый placeholder в пунктирной рамке.
  • Ввод в поле сразу подменяет placeholder на белый текст, рамка становится сплошной лаймовой.
  • Нажатие на ✓ записывает введённые значения и подставляет placeholder для незатронутых полей (принятие подсказки целиком — 1 тап).
  • Для TalkBack и автотестов каждое состояние различается по contentDescription.
