Fitty 2.0 · Гибрид #121

Гибрид A+B: 3 зоны карточки дня + валидация B + чистый заголовок «Копия дня»

Остальные 4 детали можно переключать справа прямо на живом экране, чтобы собрать финал
Тяните за ⠿ · ⋮ открывает меню · проверьте «Ошибки валидации», «Дубликат» и «Идёт тренировка»

Уже зафиксировано в этом гибриде

  • Карточка дня (из A): 3 симметричные зоны — ⠿ слева, центр-переход, ⋮ справа.
  • Ошибки валидации (из B): мягкий красноватый фон карточки + строка ошибки в дне и плашка внутри проблемного блока целей (без красной боковой полосы).
  • Дубликат дня: просто заголовок «Копия дня» без лишних баннеров и технического текста (в поле названия уже предзаполнено «… (копия)»).

Довыбрать 4 оставшиеся детали

1. Баннер активной тренировки (Редактор программы)
2. Действия «Заменить / Удалить» в раскрытом упражнении
3. Плавающий Undo-snackbar (~3 с)
4. Шторка «Выйти без сохранения?»
