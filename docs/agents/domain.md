# Domain docs

Fitty uses a single-context layout.

- Read `GLOSSARY.md` at the repository root before working with domain concepts. Use its terms in issues, proposals, and tests.
- Read decisions in `docs/adr/` that apply to the work. If a proposal conflicts with an ADR, name the ADR and explain why the decision should be revisited.
- Continue if these paths are absent. Use the `domain-modeling` skill to record terms and decisions as they are agreed.
