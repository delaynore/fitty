# Android redesign

The [Android design system and mockups](android-design-system.html) are the visual baseline for the new Fitty Android app. Open the HTML file in a browser to inspect the design system and the 20 screen and interaction mockups. The original file was supplied as “Fitty — дизайн-система и макеты Android.html”.

The [consolidated redesign prototype](android-redesign-prototype.html) layers every approved v2 UI decision on top of that baseline in one interactive and side-by-side HTML file. Keep unagreed baseline visuals intact when updating it as new prototypes are approved.

Use the mockups for screen layouts, typography, colors, components, and the interactions they illustrate. Resolve competing variants and unspecified behavior during design review. Review the gym workflow first, from choosing a training day to opening the completed workout in History.

The owner accepts losing existing local data when moving the current personal installation to the redesigned app. This exception applies to that transition only. Clearing data is optional.

## Gym workflow

- After the lifter finishes a training day, Home suggests the next day in program order and wraps to the first day after the last. The lifter can select another day and review its exercises before tapping Start.
- Reopening Fitty during a workout returns the lifter to the same exercise with the logged sets and any remaining rest time.
- Entering a complete result in an empty set row saves the set. The lifter can correct it and add extra rows beyond the planned sets.
- For the first set of an exercise, suggest the first logged set from the most recent completed workout of the same training day (falling back to the most recent workout with that exercise in another day when alternating weeks is off). When alternating heavy and light weeks is enabled, scope first-set suggestions strictly to the same training day and week variant, and use that variant's planned target on the first run. After the lifter logs a set, suggest its actual values in the next row only.
- Keep the active set row on a single compact line (`№ | Вес, кг | Повторения | ✓`) with no extra text labels on the row or source chip in the header. Show untouched Fitty suggestions as grey placeholder values inside dashed input fields; typing replaces a field's placeholder with bright white text and a solid lime border. Use a tonal checkmark button (`#303E1B`) when accepting unedited suggestions in one tap and a solid lime checkmark button (`#C5FA55`) after any edit. Tapping the checkmark records typed values together with placeholder values for untouched fields and moves the row to the green logged state (`#303E1B` with a subdued `#1F2B0D` checkmark indicator). Keep distinct state descriptions in `contentDescription` for accessibility and UI tests. Only confirmation adds a suggested row to workout history.
- For a duration exercise, show an adjustable **Today's target** (`±5 s`) initialized from the training day's planned duration, or **No target** when unset (`+` sets `0:15`, and `−` below `0:05` returns to **No target**). Changes apply to the current and subsequent sets of that exercise in the current session without altering the training program.
- Starting the exercise timer cancels any active rest timer and hides the rest timer control. With a target, the exercise timer counts down to `0:00`, signals with sound and vibration (respecting the phone's sound mode), and continues into overtime (`+0:01`, …); without a target, it counts up from `0:00` without a signal. Pressing **Stop** before `0:01` discards an accidental tap; at `0:01` or later it immediately logs the full elapsed time. Logged duration chips open an editor to correct or delete the set; lifters can also enter a duration manually or add extra sets beyond the plan. While running, the exercise timer survives switching exercises (shown as a jump-back/stop banner on other exercises) and screen locking (shown as a lock-screen live notification with a **Stop** action that logs the set without unlocking; tapping opens the exercise).
- Tap the rest timer to start (when idle) or reset (when running). Long-press it to open a menu with quick `+15 s` / `+30 s` adjustments for the running timer, default duration (presets `1:00`, `1:30`, `2:00`, `3:00` plus `±15 s`), and an auto-start toggle. Rest preferences are app-wide (default `2:00`, auto-start on) and are also available in Settings. When auto-start is on, logging any new set—including stopping the exercise timer in-app or from the lock screen—starts the rest timer (replacing the exercise timer notification); editing an already logged set does not. On the lock screen, the rest timer shows a live notification with `+30 s` and **Reset** actions, signals at `0:00` while respecting the phone's sound mode, and then disappears.
- While the `Rest timer` is running for the current exercise (started automatically after logging a set or manually on that exercise), logging a new set stays allowed through a two-tap soft guard rather than a hard lock. The active row's `✓` button visually signals that rest is running, while editing draft fields in the next row or editing/deleting an already `Logged set` stays unrestricted. The first tap on `✓` (whether accepting an untouched `Set suggestion` or saving manually edited values) does not log the set; it highlights/pulses the rest timer ring, shows a brief non-blocking confirmation hint, and arms that row's `✓` for ~3–5 seconds. A second tap on `✓` within that window logs the set immediately; otherwise the armed state resets on timeout, navigation away, or manual timer reset (which immediately restores one-tap logging). Switching to a different exercise during rest does not trigger the guard—logging a new set there works in one tap, leaving pacing across exercises to the lifter. When any new set is logged while a `Rest timer` is already running (early on the same exercise or on another exercise), Fitty restarts the `Rest timer` from the default duration (now bound to that exercise) if auto-start is on, or resets the running timer if auto-start is off. When no `Rest timer` is running, one-tap `Set suggestion` acceptance has no artificial delay. Starting the `Exercise timer` for a duration exercise remains one-tap (immediately cancelling any running `Rest timer`), and manual duration entry uses its own form without an extra guard. Visual styling of the resting/armed `✓` state, ring highlight, and confirmation hint is tracked in a separate prototype ticket.
- Visually, use the `76×76` circular rest timer next to the exercise title across all workout screens. To keep long names readable next to the ring on phone screens (`390 dp` baseline, down to `360 dp`), step down the title font size adaptively (from `26 sp` to `~17–18 sp` across up to 3 lines), keep tapping the title opening the exercise details sheet, and limit custom exercise names to 60 characters in the exercise editor. Open rest timer long-press controls in a compact modal bottom sheet focused on the default duration (`±15 s` stepper, `1:00 / 1:30 / 2:00 / 3:00` presets, and the auto-start toggle), omitting any idle placeholder and adding a single compact `+15 s` / `+30 s` top row only while rest is running. On the lock screen, use compact single-row cards in the style of the baseline mockup: the exercise timer card places **Stop** on the right (highlighting overtime `+0:xx` with a `Цель ✓` badge and subtle green tint), and the rest timer card places compact `+30 s` and **Reset** (`Сброс`) buttons on the right.
- When a weight-and-repetitions exercise has no completed workout history and no logged sets in the current session, show an optional, non-blocking weight calibration entry on the exercise screen. The entry disappears once the first set is logged. Use the training day's target repetitions when set, or a soft 8–12 repetition guideline (and a 10-repetition default for formula estimates) without requiring setup.
- Weight calibration offers two modes: feel-based trial sets (default and recommended for an unfamiliar exercise) and a repetition-maximum estimate (secondary, with a brief note to stop before technique breaks down).
  - **Feel-based trials:** The lifter performs a light trial set, enters the completed weight and repetitions, and picks one of three answers: **Too light** (rest and try the next comfortable heavier increment, direction only), **Just right** (target met with ~2–3 repetitions in reserve; completes calibration and saves the trial as the first logged set, seeding the next row's set suggestion), or **Too heavy** (rest and try the next comfortable lighter increment, plus a hint to open exercise replacement if already at the lightest weight). Intermediate trials are never saved to workout history.
  - **Repetition-maximum estimate:** The lifter performs one set of clean repetitions to near the technique limit and enters the completed weight and repetitions. Fitty estimates 1RM using the formula selected in Settings (default **Epley**; selectable with short hints among Epley, Brzycki, O'Conner, Lombardi, Lander, Mayhew, and Wathan; `1RM = weight` for 1 rep) and inverts the same formula for `target + 2` repetitions (~2 repetitions in reserve), reminding the lifter to round to the nearest equipment increment. Above 15 repetitions, do not calculate an estimate—prompt the lifter to use a heavier weight or switch to feel-based trials. Do not save the test set to workout history; prefill the estimated result as the first row's set suggestion.
- The lifter can exit weight calibration at any time back to the empty set list without saving trials. Rest between trials uses the regular manual rest timer. Unfinished calibration state is ephemeral and is not persisted across app restarts.
- Visually, place the weight calibration entry as a compact tonal chip (`Подобрать вес`) next to the exercise plan tag. Tapping it opens a `#1C231C` bottom sheet that keeps the exercise header and `76×76` circular rest timer visible and interactive above. Put a segmented mode switch at the top of the sheet (**Feel-based** selected by default with a recommended badge | **Rep-max estimate**). In feel-based trials, show weight and repetition fields with three vertical answer cards (`Too light`, `Just right`, and `Too heavy` with an inline **Replace exercise** button). In repetition-maximum estimates, show a clickable formula row (`Формула: … · Сменить`) that opens the 7-formula radio list (`Формула расчёта`) with one-line hints and live previews; changing the formula here updates the app-wide Settings preference. Render Cyrillic headings and `1RM` metadata in `Inter`, reserving `Barlow Condensed` for large numeric readouts. After prefilling an estimate into row 1 as a `Set suggestion`, show a floating bottom snackbar above the bottom navigation bar (auto-hides, swipe down to dismiss, with a **Reset** action that clears the suggestion and returns to the estimate); do not show a snackbar when logging a set (either manually or via **Just right**).

## Heavy and light weeks and progression

- Each `training program` has an **Alternate heavy and light weeks** toggle (off by default) and a program-level light-week rule selector with three modes: **Easier sets** (default), **Fewer sets (−1)**, and **Manual** (copies heavy targets without auto-calculation). When first enabled on an existing program, current exercise targets become the heavy-week targets, light-week targets auto-calculate immediately under **Easier sets** (for exercises with **Progression** on; unchanged when off), and Fitty proposes starting with a heavy week (changeable before starting the pass).
- A `training week` lasts one full pass through the program's training days, independent of calendar boundaries or breaks between workouts. Days may be performed in any order or explicitly skipped for the current pass only. Once all days in the pass are completed or skipped, Fitty proposes the opposite week variant.
- The chosen week variant is locked for the full pass; easing a single session mid-pass uses one-off session lightening instead. When a lifter wants to leave an active pass early (for example, energy returns mid-light-week or a full planned deload is needed mid-heavy-week), they can explicitly **End week early** (`Завершить неделю досрочно`) from the locked-week sheet on Home: already completed days stay in `Workout history` under their actual variant, the remaining days close, and Fitty immediately opens a fresh pass proposing the opposite week variant. Removing a training day mid-pass removes it from the remaining days (completing the pass if none remain); adding a day includes it as uncompleted in the current pass.
- Heavy weeks drive progression; light weeks serve as planned deloads. `Training day` plans store only sets and targets (no planned weight field; working weight stays in workout history and isolated heavy/light `Set suggestion`). In the program editor, heavy and light targets appear side by side, with repetition ranges and a one-tap `8–12` preset available for both `Weight and repetitions` and `Repetitions`.
- Each exercise in a `Training day` has a **Progression** toggle (on by default for `Weight and repetitions` and `Repetitions`; off by default for `Duration` and `Distance`). When **Progression** is off (such as warm-up or maintenance work), Fitty hides proactive progression prompts for that exercise and leaves its auto-calculated planned light-week target equal to its heavy target (still manually editable).
- Planned light-week auto-calculation (for exercises with **Progression** on) and one-off session lightening share the same per-type formulas:
  - **Easier sets:**
    - `Weight and repetitions` and `Repetitions`: subtract `2` repetitions when the exact target or range lower bound is `≥ 5` (for example, `8–12` → `6–10`, `5` → `3`). For short targets `≤ 4` (such as `1–3`, `3`, `4`): `Weight and repetitions` keeps the repetition target and shows a "lower weight by feel" hint; `Repetitions` subtracts `1` repetition when `≥ 2` (`4` → `3`, `2–4` → `1–3`) or keeps `1` with an "easier by feel" hint.
    - `Duration`: `80%` rounded to the nearest `5 s`, capped at `original − 5 s` and floored at `5 s` (`60 s` → `50 s`, `45 s` → `35 s`, `40 s` → `30 s`, `30 s` → `25 s`, `20 s` → `15 s`, `15 s` → `10 s`, `10 s` → `5 s`); targets `≤ 5 s` stay unchanged with an "easier by feel" hint.
    - `Distance`: `80%` rounded to an adaptive step (`≥ 1000 m` → `100 m`, `100–999 m` → `50 m`, `10–99 m` → `5 m`, `< 10 m` → `1 m`), strictly less than the original when `> 1 m` and floored at `1 m`.
    - **Unset target:** stays empty in a planned light week (showing an "easier by feel" hint during the workout); during one-off **Easier sets** lightening, the formula applies to the last normal `Logged set` (prefilling row 1 `Set suggestion` or `Duration` `Session target`), or stays empty with the same hint when there is no history.
  - **Fewer sets (−1):** subtracts `1` set when planned sets `≥ 2`; keeps `1` set with an "easier by feel" hint when planned sets `= 1`; leaves unset set counts empty in the plan (starting with 3 rows instead of 4 during the workout).
- Changing the program's light-week rule recalculates all auto-calculated exercises immediately. Manually editing either light sets or light target marks that exercise's entire light target as overridden—subsequent changes to the heavy target, program rule, or **Progression** toggle leave it untouched until the lifter explicitly taps **Reset to program rule** (recalculating both fields; not shown in **Manual** program mode).
- Visually on Home, keep the clean baseline layout when alternating heavy and light weeks is off (no week controls, pass progress, or skip-day actions). When alternating is enabled, embed the `Training week` controls inside the footer of the green program card (`#303E1B`) so vertical space below remains clear for `Readiness check-in` and the day selector: before the pass starts (`0/N`), show a one-tap segmented toggle (`Тяжёлая` / `Лёгкая`, marking the proposed plan, using the unified sky blue `#5CC8FA` light-week accent across the segment, selected day chip, preview tags, and start button) that immediately updates the day's exercise preview targets below; mid-pass (`≥ 1` day completed or skipped), collapse the footer into a single compact row with a locked week pill (`🔒 Тяжёлая неделя` / `🔒 Лёгкая неделя`, paired with the heavy/light indicator dot) and pass progress dots (`X/N`). Tapping the locked pill opens a `#1C231C` bottom sheet explaining why the variant stays locked and offering **End week early** (`Завершить неделю досрочно`, with a second-step confirmation inside the sheet). Keep horizontal day chips with compact status marks (`✓` completed, dashed muted `⊘` skipped) and place day-level pass controls in the selected day's exercise-list card header (`Пропустить день` for an uncompleted day, `Вернуть в неделю` for a skipped day in the current pass, or `Выполнен в проходе` for a completed day). Tapping `Пропустить день` opens a `#1C231C` confirmation bottom sheet explaining that the skip applies to the current pass only (explicitly warning on the last remaining day that the pass will close and Fitty will propose the opposite week). Omit rollover banners and "pass completed" snackbars after normal workout completion or pass transitions; show a brief auto-hiding `Отменить` undo snackbar only after an explicit day skip or early pass completion.
- Visually on the workout screen (variant A), show the week label (`Тяжёлая неделя` or `Лёгкая неделя`) in the top bar next to the back button, keep the planned target chip under the exercise title, and show the first-set suggestion inside row 1's fields. Do not show `Weight calibration` (`Подобрать вес`) on the first light week when the exercise already has completed history from a heavy week.
- `Workout history` records the actually performed variant (for example, `День Б · Лёгкая`, or just `День Б` when alternating is off). Progress comparisons and workout summaries compare against the same training day and week variant.
- Workout summaries show the actual change across all sets for all four `Exercise type`s (total repetitions, total duration, or total distance). For exercises with **Progression** enabled (when app-wide **Load prompts** in Settings is on, on by default), Fitty uses classic double progression on regular and heavy sessions, showing direction-only prompts without modifying the program or computing kilogram steps (leaving the previous `Set suggestion` in row 1):
  - **Target reached (all four types when a target is set):** completing the exact target or upper bound across all planned sets (at one weight for `Weight and repetitions`) suggests trying a heavier weight (`Weight and repetitions`), increasing the repetition target (`Repetitions`), increasing duration (`Duration`), or increasing distance (`Distance`).
  - **Unset target:** only `Weight and repetitions` triggers an increase-weight prompt (when total repetitions grow at the same weight and set count); the other three types rely on summary deltas alone.
  - **Decrease load:** after two comparable sessions where every set falls below a repetition range's lower bound without total-repetition growth, suggest lowering load for repetition-range exercises (`Weight and repetitions` and `Repetitions` with a range); do not show decrease-load prompts for exact `Duration` or `Distance` targets.
  - Alternative progression models (dynamic double progression, to-failure top-set triggers, rep-goal totals) are deferred beyond v2.
- Visually, on the workout screen, keep the plan chip alone under the exercise header and show proactive progression prompts as a compact contextual strip below it with a `3 dp` left accent bar (lime `#C5FA55` for trying heavier, calm amber `#F5C469` for trying lighter—distinct from destructive error `#FFB4AB`), a one-line reason, and a dismiss `×` button. The prompt requires zero taps to ignore, hides automatically after logging set 1, and disappears completely when **Load prompts** is off or on light/lightened sessions. On the workout summary screen, show a comparison hero card at the top summarizing overall gains against the prior comparable session, group exercises into **Progress** (soft green tint `#161E13` / `#2A381D`) and **Other exercises**, and render each exercise in a compact card with a delta pill on the right, a muted `Было:` line when changed, and per-set color-highlighted pills (solid lime `#C5FA55` for improved sets or increased weight, tonal green `#303E1B` for unchanged sets in an improved exercise, calm amber `#2B2416` / `#F5C469` for dipped sets, neutral `#252D24` for unchanged or first-time sets), keeping the summary strictly factual without next-session advice lines.

## Readiness check-in and one-off session lightening

- Before tapping **Start**, Home shows an optional, non-blocking `Readiness check-in` (**Recovered** / **Feeling fatigued**). Leaving it untouched skips the prompt with zero extra taps. Choosing **Feeling fatigued** offers to lighten today's `Workout session` right away while keeping the underlying `Training program` unchanged.
- An app-wide **Readiness check-in** toggle in Settings (on by default) hides the pre-workout prompt on Home (leaving Home clean) while keeping manual mid-workout lightening available inside the workout screen.
- When accepting one-off lightening—before start or mid-workout—the lifter chooses between two modes:
  - **Fewer sets (−1):** removes one planned set from exercises with two or more planned sets (keeping at least one; three default rows instead of four when no set count is planned), keeps the normal working `Set suggestion`, and notes that weight or effort can also be dialed down by feel.
  - **Easier sets:** eases each exercise's `Session target` relative to today's planned target using the shared per-type formulas above (`−2` repetitions or short-range fallback for repetition-based exercises; `~80%` with `5 s` rounding for `Duration` and adaptive meter rounding for `Distance`; or derived from the last normal `Logged set` when no target is set). In this mode, row 1 prefills the previous normal working weight paired with the lightened repetition or distance target for one-tap acceptance, and `Duration` exercises update the exercise timer's `Session target`.
- One-off lightening works on regular, heavy, and planned light weeks alike, always calculating relative to today's target rather than substituting a planned light week, and applies to all exercises in today's session (including exercises with **Progression** off). Completing a `Lightened session` counts that `Training day` as completed in the current `Training week` pass without switching the week variant.
- Mid-workout, the lifter can enable, switch between the two lightening modes, or turn lightening off for the remaining exercises and unlogged sets of the `In-progress workout` without altering already logged `Logged set` entries; active mode and lightened-set state persist across app restarts. Turning lightening off before logging any set in lightened mode keeps the session normal. Logging at least one set while lightened marks the entire `Workout session` as lightened. If logged sets in the current exercise already meet or exceed the reduced set target, the exercise counts as complete immediately (while still allowing manual extra sets).
- A `Lightened session` is isolated from future `Set suggestion` lookups, progression prompts (increase/decrease load), and `Weight calibration` eligibility (if an exercise's only history is a lightened session, `Weight calibration` remains available on the next normal session). Proactive progression prompts are hidden during a lightened session, and its workout summary shows actual completed work without negative deltas against prior normal sessions.
- `Workout history` records only whether a session was lightened (never a separate readiness log when lightening was declined). Heavy, light, and lightened sessions use distinct semantic visual indicators (color coding paired with concise scannable markers/accessibility descriptions) across Home, the workout header, summaries, and `Workout history`.
- Visually, represent heavy, planned light, and one-off lightened load types consistently across Home, the workout header, summaries, and `Workout history` using minimalist glowing `8 dp` colored indicator dots ("lamps")—warm amber (`#F59E42`) for heavy weeks, cool sky blue (`#5CC8FA`) for planned light weeks, and soft lavender (`#C09BFF`) for one-off lightened sessions—shown side by side when combined (for example, heavy + lightened or light + lightened) and paired with clear `contentDescription` strings. In `Workout history`, combine these `8 dp` lamps (inside a non-truncating week/lightened badge) with a `4 dp` colored left edge ribbon on the card matching the workout's load type (single-color for heavy, planned light, or regular lightened; `50 / 50` two-tone split when combined such as heavy + lightened or light + lightened; omitted on plain regular sessions). On Home, place the `Readiness check-in` card high under the program banner (above the training-day selector) with a prominent accented border and dark gradient surface, pulse icon, brief action-oriented copy, and two color-tinted buttons (**Recovered** / **Feeling fatigued · lighten**); tapping **Feeling fatigued** expands the two lightening modes (**Fewer sets (−1)** and **Easier sets**, plus **Keep normal plan**) inline inside the card and recalculates the day's exercise preview chips below immediately, while leaving it untouched starts the normal workout in zero extra taps. During a workout, keep the week label with its lamp in the top bar next to the back button and place a compact **Lighten** (`Облегчить`) button on the top-right next to the exercise counter (`X/N`) that opens a `#1C231C` bottom sheet to enable, switch between the two modes, or return to the normal plan (glowing with a lavender lamp and the active mode label while enabled).

## Text length limits and long-text display

- Keep a single name per entity—do not introduce separate optional short-name (`displayName`) fields for `Training program`, `Training day`, or catalog exercises. Measure text length by visible characters (grapheme clusters, so an emoji counts as 1) after trimming leading and trailing whitespace.
- Enforce soft length limits across all four persistent user-editable text fields: **Training program name** (`60`), **Training day name** (`40`), **Custom exercise name** (`60`, applying to both creation and renaming without altering past `Workout history` snapshots), and **Exercise technique** (`500`). Typing, pasting, or handing off a query from catalog search to exercise creation never silently truncates text; exceeding the limit highlights the field in error (`#FFB4AB`) with its counter and blocks saving until shortened. Show the `X / 500` counter continuously for **Exercise technique**, and show `X / N` counters for name fields starting at `80%` of the limit (`48 / 60`, `32 / 40`) and on overflow.
- Required name fields (program, day, custom exercise) are single-line (replacing pasted line breaks with spaces), trim surrounding spaces on save, keep the **Save** button tappable, and display an inline empty-field error on save attempt. **Exercise technique** is optional and multiline; empty or whitespace-only input saves as absent. Non-persistent search fields (exercise catalog search and muscle filter search) apply a technical `100`-character input ceiling; numeric fields (sets, targets, weight, repetitions, duration, distance) remain under numeric format and range validation. No legacy over-limit migration/editing exceptions are needed because the redesigned app starts clean.
- Use a three-tier display strategy across screens on phone widths down to `360 dp`, with large system font scaling (`1.3×–1.5×`), and for unbroken words without spaces (allowing intra-word breaks inside allowed lines and never overlapping sibling elements such as `3 × 8`, the `76×76` rest timer, buttons, or drag handles):
  - **1 line + `…`:** compact elements—Home training-day chips (capped at `~220 dp` width so neighboring days stay visible, with the selected day's full name shown in up to 2 lines as the exercise-list card header directly below), undo snackbars (`Удалён день …` / `Удалён подход · …`), other-exercise running timer banners, and lock-screen live notifications (truncating only the exercise name in `Название · подход 3 из 3` so the set suffix always stays intact).
  - **Up to 2 lines + `…`:** list cards and rows—Home program card, Home exercise preview rows, My Programs list, program/day editor rows, `Exercise catalog` list, **All exercises** and **Replace exercise** sheets, and `Workout history` list cards (keeping week-variant/lightened markers as separate non-truncating badges rather than appending them to the truncated day title).
  - **Full wrap (no truncation):** detail screens and confirmation surfaces—program details header and day headings, exercise card (name and technique), `Workout history` workout details, the workout exercise-details bottom sheet, set-edit sheets, and confirmation dialogs. In the workout header next to the `76×76` rest timer, step font size adaptively (`26 sp` down to `~17–18 sp` across up to 3 lines) and fall back to `…` at the end of line 3 under extreme font scaling or unbroken words, with tapping the title opening the full name in the exercise-details sheet.
